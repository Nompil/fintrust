What should my file contain?

A CSV is a spreadsheet saved as plain text. It must include these columns: account_id, amount, tx_date and tx_type. Account IDs must already exist in FinTrust.

Optional columns include currency, merchant and country. Existing sample files show the expected format. Re-uploading an unchanged file does not add its transactions again through this upload page.
